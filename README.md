# sutton-and-barto-from-scratch-2-monte-carlo-and-temporal-difference-learning
Implement the model-free prediction and control methods of Sutton and Barto chapters 5 and 6. Build a blackjack simulator and estimate state values with first-visit and every-visit Monte Carlo, learn a blackjack policy with on-policy epsilon-soft MC control, evaluate a target policy off-policy with ordinary and weighted importance sampling,…
